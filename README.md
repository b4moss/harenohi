# @b4moss/harenohi

祝日演算ライブラリ。当初は `npm` パッケージとして開発。
将来的に、OSSとして公開予定。

## 主な責務

- 祝日のデータを演算して返却する
- 各国・各文化圏の祝日に対応する
    - ただし、当初は日本の祝日から。
 
## 日本祝日データの生成方針

### 未来の祝日

- 法令で定まっている日は、動的演算
- 春分の日・秋分の日の天体観測に基づく設定は、動的だが概算(実際の公布と異なったとしても許容)

### 来年の祝日

- 政府発表の時期にActionsワークフローを回し、CSVの取得を行う
- パースして、ライブラリに追加

### 過去の祝日

- 政府がCSVを公表しているので、それを取り込んでパース
- 戦後の現在の祝日法が定められた時期以降でOK
- それ以前は当ライブラリのスコープ外

## 大まかな開発スコープ

1. 祝日演算APIの定義・開発
2. 日本の祝日定義と、演算・取得方法
  - `kohki/shikata-kohki-life`に、TSによる祝日演算は用意されているはず。これを再利用する。
3. 上記をもって1.0リリース可能とする。他文化圏の祝日データは、`After-v1.0.0` とする。
