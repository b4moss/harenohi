# @b4moss/harenohi

祝日演算ライブラリ。当初は `npm` パッケージとして開発。
将来的に、OSSとして公開予定。

## 主な責務

- 祝日のデータを演算して返却する
- 各国・各文化圏の祝日に対応する
    - ただし、当初は日本の祝日から。

## 大まかな開発スコープ

1. 祝日演算APIの定義・開発
2. 日本の祝日定義と、演算・取得方法
  - `kohki/shikata-kohki-life`に、TSによる祝日演算は用意されているはず。これを再利用する。
3. 上記をもって1.0リリース可能とする。他文化圏の祝日データは、`After-v1.0.0` とする。
