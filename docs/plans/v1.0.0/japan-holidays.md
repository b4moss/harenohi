# 日本の祝日 — 演算と振る舞い

根拠: [国民の祝日に関する法律](https://laws.e-gov.go.jp/law/323AC1000000178)。PO 初期ドキュメントの生成方針を崩さない。

## 用語

| 用語 | 意味 |
|------|------|
| 国民の祝日 | 法で定める祝日 |
| 振替休日 | 祝日が日曜日のとき、直後の「国民の祝日でない日」 |
| 国民の休日 | 前日と翌日が国民の祝日である「国民の祝日でない日」 |
| オーバーライド | 年単位の静的データ。ある年に存在すれば演算より優先 |

本ライブラリの返却対象は上記すべて（名称で区別する）。

## 解決順序

1. 引数の年についてオーバーライドがあれば、それを正とする（演算しない）
2. なければ、法令に基づく演算でベース祝日を作る
3. 振替休日を付与する
4. 国民の休日を付与する
5. 日付で一意化し、昇順ソートする

## ベース祝日（現行法・現天皇誕生日前提）

固定日・ハッピーマンデー・春分秋分。名称は法令・政府 CSV に合わせる。

| 名称 | 求め方 |
|------|--------|
| 元日 | 1/1 |
| 成人の日 | 1月第2月曜日 |
| 建国記念の日 | 2/11 |
| 天皇誕生日 | 2/23（代替わり時は版上げでハードコード更新。その年より前はオーバーライド） |
| 春分の日 | 概算演算（後述） |
| 昭和の日 | 4/29 |
| 憲法記念日 | 5/3 |
| みどりの日 | 5/4 |
| こどもの日 | 5/5 |
| 海の日 | 7月第3月曜日 |
| 山の日 | 8/11 |
| 敬老の日 | 9月第3月曜日 |
| 秋分の日 | 概算演算（後述） |
| スポーツの日 | 10月第2月曜日 |
| 文化の日 | 11/3 |
| 勤労感謝の日 | 11/23 |

歴史的に名称・日付が変わった年（例: 体育の日、海の日のオリンピック年、即位関連）は、オーバーライドで吸収する。演算ロジックに全歴史分岐を詰め込まない。

## 春分・秋分

- 天体観測に基づく公布があるが、本ライブラリは **概算式で動的演算**する
- 公布と異なる結果になっても v1 では許容する（PO 方針）
- 差分が判明した年・年次は、政府 CSV 由来のオーバーライドで上書きする（U-05 決定）

概算式の具体式は参照実装（`equinox.ts`）を移植する。式の差し替えは PATCH/MINOR でよいが、結果が変わる場合は CHANGELOG に明記する。

## 振替休日

- ベース祝日が日曜日に当たるとき、その直後で最初の「祝日でない日」を `振替休日` とする
- **春分・秋分も振替対象に含める**（法令どおり。U-04 決定。参照実装は除外しているが、本パッケージでは含めない）

## 国民の休日

- ある日の前日と翌日がいずれも国民の祝日であり、その日自身が国民の祝日でないとき、その日を `国民の休日` とする
- 典型: GW の橋渡し

## 対象期間

- 開始: 1948（祝日法施行。U-02 / D-15 決定）
- 終了: 上限なし（未来は演算。来年の確定分は CSV 取り込みでオーバーライド化しうる）
- 開始より前: 演算対象外。API は警告を出し空の結果（祝日なし）を返す（エラーにしない）

## 天皇誕生日・法改正

- 現在の固定値（2/23）を演算に使う
- 代替わりや法改正は、該当年からオーバーライドまたは定数更新 + 版上げで対応する（事前の自動推定はしない）

## テスト観点（ドメイン）

- 固定日・ハッピーマンデーの既知年
- 振替（日曜祝日、連休での振替のずらし）
- 国民の休日（GW）
- 春分・秋分の概算が妥当な範囲の日付になること
- オーバーライド年は CSV 由来と一致し、演算を使わないこと
- オリンピック年など例外年はオーバーライドで期待値一致
