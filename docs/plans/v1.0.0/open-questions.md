| A | `@b4moss/harenohi`（PO 初期 README・OSS 組織） |

## U-02 対象開始年 — 決定済み（2026-10-20 PO）

| 案 | 内容 |
|----|------|
| A | 1948（祝日法施行） |
| B | 1955 など CSV が安定して揃う年 |
| C | オーバーライドがある最初の年のみサポート |

**決定: 1948 年から対応。** 1948 年より前の年を聞かれた場合は**エラーではなく空の結果（祝日なし）**を返す。警告の届け方は **N-H1: `options.onWarning?`**（未指定時は何もしない）（D-15＋N-H1）。
