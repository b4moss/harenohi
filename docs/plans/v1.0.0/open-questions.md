# 未決項目

質問で止めず、選択肢と推奨を書く。PO レビューで確定する。

## U-01 npm スコープ名

| 案 | 内容 |
|----|------|
| A | `@b4moss/harenohi`（PO 初期 README・OSS 組織） |
| B | `@b4m/harenohi`（社内 packages 組織に合わせる） |
| C | 当面 `@b4m`、OSS 公開時に `@b4moss` へ移す |

**推奨: A。** 初期ドキュメントが `@b4moss` を掲げ、将来 OSS 予定。社内だけ使う間も同じ名前でよい（framewaku の社内専用 `@b4m` とは役割が異なる）。

## U-02 対象開始年

| 案 | 内容 |
|----|------|
| A | 1948（祝日法施行） |
| B | 1955 など CSV が安定して揃う年 |
| C | オーバーライドがある最初の年のみサポート |

**推奨: A。** PO の「戦後の現行祝日法以降」。欠年は CSV で埋める。無い年は演算（ただし開始直後の法改正はオーバーライド優先）。

## U-03 日付ライブラリ依存

| 案 | 内容 |
|----|------|
| A | 外部日付ライブラリなし（`Date` / 自前ヘルパ）。paycle と同方針 |
| B | Day.js を依存に残す（参照実装そのまま） |
| C | より小さい専用ライブラリ

**推奨: A。** 日付のみ・ブラウザ/Node 両対応・依存最小化。移植時に Day.js 呼び出しを剥がす。

## U-04 春分・秋分の振替休日

| 案 | 内容 |
|----|------|
| A | 法令どおり振替対象に含める |
| B | 参照実装どおり春分・秋分は振替対象外 |

**推奨: A。** 法に合わせる。参照実装の除外は本パッケージでは踏襲しない。差分はテストで明示。

## U-05 概算と公布の差分

| 案 | 内容 |
|----|------|
| A | v1 は概算許容。差分は確定後に CSV オーバーライドで吸収（PO 方針） |
| B | 公布まで該当年の春分秋分を返さない / エラー |
| C | 外部の天文 API を実行時呼び出し |

**推奨: A。** PO の「概算許容」を維持。C はランタイム依存が増えスコープ外。

## U-06 公開レジストリと時期

| 案 | 内容 |
|----|------|

| C | GitHub Packages のみ |

**推奨: A。** 「当初 npm、将来 OSS」の段階に合う。公開チェックリストは v1 後の plans でよい。

## U-07 ロケール引数

| 案 | 内容 |

| A | v1 は日本固定。引数なし |

## U-08 モジュール形式
