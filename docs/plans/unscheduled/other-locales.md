# 他文化圏の祝日（After-v1.0.0）

## 目的

日本以外の国・文化圏の祝日を、同じライブラリから扱えるようにする。

## ざっくり範囲

- ロケールまたは地域コードごとの祝日演算・データ
- 共通の `Holiday` 形は維持し、取得 API にロケールを足す想定

## やらぬこと（このスタブの時点）

- v1.0.0 の日本 API を待たずにロケール必須化すること
- 全国連カバーを初期目標にすること

※ **日本の祝日名の多言語表記**（Issue #10）は本スタブとは別件。正本: [../../specs/display-title-i18n.md](../../specs/display-title-i18n.md)。

## 後日詳細

- 優先する国・地域
- データソース（法令 / オープンデータ）
- パッケージ分割（モノレポ vs ロケール別パッケージ）か単一パッケージか
